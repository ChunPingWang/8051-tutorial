# 第 2 課:按鈕控制 LED(組合語言版)

## 這個範例做什麼
讀取接在 P1.5 的按鈕:按下時點亮 P1.4 的 LED,放開則熄滅。

## 接線
```
LED : P1.4 ──► 220Ω ──► LED 長腳(+),LED 短腳(−)──► GND
按鈕: P1.5 ──────[ 按鈕 ]────── GND
```
- 利用準雙向腳的**內部弱上拉**,按鈕不必外接上拉電阻。
- 放開 → P1.5 = 1;按下 → P1.5 = 0(低電位有效)。
- ⚠️ 板載 LED 極性可能相反,必要時對調點滅邏輯。

## 編譯與燒錄
```bash
make        # 組譯 + 連結,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
平常 LED 滅;按住按鈕時 LED 亮,放開立刻滅。與 C 版一致。

## 程式重點
- `anl P1M1,#0xCF` 一次清掉 P1.4、P1.5 的模式位;再分別設推挽 / 準雙向。
- 讀準雙向腳前先 `setb SW`(對應 C 的 `SW = 1`)。
- `jb SW, led_off`:P1.5 為 1(放開)就跳去關燈 —— 這就是組語版的 `if`。
- 原理詳見 [`../../docs/03-按鈕輸入與GPIO.md`](../../docs/03-按鈕輸入與GPIO.md)。

## 對照另一個版本
→ C 版:[`../../c/02-button/`](../../c/02-button/)。C 的 `if (SW==0)` 等同組語用 `jb`/`jnb` 依位元決定跳躍。

## 練習
1. 改用 `jnb` 改寫判斷邏輯,體會兩者差異。
2. 做「按一下切換一次」(toggle),並加去彈跳延時。
3. 用兩顆按鈕分別控制開、關。
