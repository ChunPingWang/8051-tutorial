# 第 3 課:計時器中斷 — 精準閃爍(組合語言版)

## 這個範例做什麼
用 Timer0 中斷讓 P1.4 的 LED **每 0.5 秒**精準翻轉一次,主程式只是空轉。

## 接線
```
P1.4 --> 220Ω --> LED 長腳(+),LED 短腳(−)--> GND
```
- ⚠️ 板載 LED 極性可能相反,必要時對調。

## 編譯與燒錄
```bash
make        # 組譯 + 連結,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
LED 穩定地每 0.5 秒切換一次,與 C 版完全相同。

## 程式重點
- 中斷向量要自己擺:`.org 0x000B` 放 `ljmp timer0_isr`(0x000B 是 Timer0 向量)。
- ISR 開頭 `push acc`/`push psw`、結尾 `pop` 還原,最後用 **`reti`(不是 `ret`)**。
- 16 位元計數用兩個記憶體位元組 `cnt_lo`/`cnt_hi`,靠 `add` + `addc` 處理進位,`cjne` 比較 500。
- `cpl LED` 翻轉腳位。
- 原理詳見 [`../../docs/04-計時器與中斷.md`](../../docs/04-計時器與中斷.md)。

## 對照另一個版本
→ C 版:[`../../c/03-timer/`](../../c/03-timer/)。C 的 `__interrupt(1)` 自動完成向量接線、暫存器保存與 `reti`;組語必須手動處理這一切。

## 練習
1. 改比較值 `0x01F4`(500),做成每 0.25 秒閃一次。
2. 試著不 `push psw`,觀察程式為何會出錯,體會保存暫存器的重要。
3. 把主迴圈改成讀按鈕,驗證中斷與主程式同時運作。
