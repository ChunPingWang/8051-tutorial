# 第 1 課:LED 閃爍(組合語言版)

## 這個範例做什麼
讓接在 P1.4 的 LED 每隔約 0.3 秒亮滅一次,用最底層的組合語言完成第一支程式。

## 接線
```
P1.4 --> 220Ω 電阻 --> LED 長腳(+)
                       LED 短腳(−)--> GND
```
- P1.4 輸出高電位 → LED 亮;輸出低電位 → LED 滅。
- ⚠️ 若你用「板載 LED」,它常是低電位才亮(極性相反);此時把 `setb LED` 與 `clr LED` 對調即可。

## 編譯與燒錄
```bash
make        # 組譯 + 連結,產生可燒錄的 main.hex
make flash  # 把 main.hex 燒進 N76E003
make clean  # 刪除所有編譯產生的檔案
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 裡的 udev 權限設定。

## 預期結果
LED 以大約每 0.3 秒一次的節奏持續閃爍,和 C 版完全一樣。

## 程式重點
- `.area CODE (ABS,CODE)` + `.org 0x0000` 放重置向量,`ljmp start` 跳到主程式。
- `anl` / `orl` 對應 C 的 `&` / `|`,用來設定 GPIO 模式。
- `setb` / `clr` 控制單一位元(腳位);`djnz` 做延時迴圈;`sjmp` 構成無窮迴圈。
- 注意:這版 `sdas8051` **不需要也不接受 `.end`**。
- 原理詳見 [`../../docs/02-GPIO與LED閃爍.md`](../../docs/02-GPIO與LED閃爍.md)。

## 對照另一個版本
→ C 版:[`../../c/01-blink/`](../../c/01-blink/)。C 把 `setb`/`clr`/`djnz` 包裝成人看得懂的 `P14=1;` 與 `for` 迴圈。

## 練習
1. 調整 `delay` 裡 `R2` 的值,改變閃爍快慢。
2. 改用另一支腳(例如 P1.5)。
3. 讀 `main.lst` 列表檔,看每一行組語被組成哪些機器碼。
