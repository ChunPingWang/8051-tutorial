# 第 1 課:LED 閃爍(C 版)

## 這個範例做什麼
讓接在 P1.4 的 LED 每隔約 0.3 秒亮滅一次,帶你完成人生第一支微控制器程式。

## 接線
```
P1.4 ──► 220Ω 電阻 ──► LED 長腳(+)
                       LED 短腳(−)──► GND
```
- P1.4 輸出高電位 → LED 亮;輸出低電位 → LED 滅。
- ⚠️ 若你用「板載 LED」,它常是低電位才亮(極性相反);此時把程式裡的 `LED_ON` / `LED_OFF` 對調即可。

## 編譯與燒錄
```bash
make        # 編譯,產生可燒錄的 main.hex
make flash  # 把 main.hex 燒進 N76E003
make clean  # 刪除所有編譯產生的檔案
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 裡的 udev 權限設定,否則 `make flash` 會出現權限錯誤。

## 預期結果
LED 以大約每 0.3 秒一次的節奏持續閃爍(亮、滅、亮、滅…),不會停止。

## 程式重點
- 用 `P1M1`/`P1M2` 把 P1.4 設為**推挽輸出**,才能有力地驅動 LED。
- 用位元運算 `&= ~(1<<4)` 與 `|= (1<<4)` 只改第 4 位、不動其他腳位。
- `while(1)` 主迴圈 + 軟體延時(空轉迴圈,不精準)。
- 原理詳見 [`../../docs/02-GPIO與LED閃爍.md`](../../docs/02-GPIO與LED閃爍.md)。

## 對照另一個版本
→ 組語版:[`../../asm/01-blink/`](../../asm/01-blink/)。兩版步驟一一對應;C 的 `P14 = 1;` 在組語裡就是 `setb`,延時則用 `djnz` 迴圈。

## 練習
1. 調整延時圈數,讓閃爍變快或變慢。
2. 改用另一支腳(例如 P1.5),程式與接線一起改。
3. 做出「亮 1 下、暗、亮 2 下、暗」的節奏。
