# 第 2 課:按鈕控制 LED(C 版)

## 這個範例做什麼
讀取接在 P1.5 的按鈕:按下時點亮 P1.4 的 LED,放開則熄滅。學會「輸入」。

## 接線
```
LED : P1.4 --> 220Ω --> LED 長腳(+),LED 短腳(−)--> GND
按鈕: P1.5 ──────[ 按鈕 ]────── GND
```
- 利用 N76E003 準雙向腳的**內部弱上拉**,按鈕不必外接上拉電阻。
- 放開 → P1.5 讀到 1;按下 → P1.5 讀到 0(低電位有效)。
- ⚠️ 板載 LED 極性可能相反,必要時對調點滅邏輯。

## 編譯與燒錄
```bash
make        # 編譯,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
平常 LED 滅;按住按鈕時 LED 亮,放開立刻滅。反應即時。

## 程式重點
- P1.4 設推挽輸出,P1.5 設準雙向輸入;準雙向腳讀取前要先寫 `SW = 1`。
- 用 `if (SW == 0)` 判斷按下(低電位有效)。
- 這種一直檢查輸入的做法叫「輪詢 (polling)」。
- 原理詳見 [`../../docs/03-按鈕輸入與GPIO.md`](../../docs/03-按鈕輸入與GPIO.md)。

## 對照另一個版本

## 練習
1. 改成「按一下切換一次」(toggle),並加上約 20ms 去彈跳。
2. 用兩顆按鈕分別控制開、關。
3. 結合第 1 課:平常閃爍,按住時改為恆亮。
