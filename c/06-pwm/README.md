# 第 6 課:PWM 呼吸燈(C 版)

## 這個範例做什麼
用硬體 PWM 控制 P1.2 的 LED 亮度,做出由暗漸亮、再漸暗、不斷循環的「呼吸燈」。

## 接線
```
P1.2 --> 220Ω --> LED 長腳(+),LED 短腳(−)--> GND
```
- ⚠️ 這一課 LED 要接 **P1.2**(不是前幾課的 P1.4)。因為亮度是由 PWM0 這個硬體
  通道產生的,而 PWM0 的輸出腳固定在 P1.2。
- ⚠️ 板載 LED 極性可能相反,必要時改 `PNP` 極性或對調接法。

## 編譯與燒錄
```bash
make        # 編譯,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
P1.2 的 LED 像呼吸一樣,亮度平滑地增強到最亮、再減弱到全暗,週而復始(一個呼吸
循環約 2~3 秒)。整個過程 CPU 其實很閒 —— 波形是硬體 PWM 自動產生的。

## 程式重點
- PWM0 固定輸出到 P1.2,用 `PIOCON0 |= 0x01` 啟用。
- 週期由 `{PWMPH, PWMPL}` 設定(255 → 256 階);頻率 ≈ (16MHz/128)/256 ≈ 488Hz。
- 亮度 = 工作週期 `PWM0L`(0~255);**每次改完都要 `LOAD = 1`** 才會生效。
- 原理詳見 [`../../docs/08-PWM.md`](../../docs/08-PWM.md)。

## 進階範例:正弦加減速控制直流馬達
同資料夾另附 [`motor_sine.c`](motor_sine.c):用正弦查表讓**直流馬達**轉速平滑地
加速、減速、循環。
- ⚠️ **馬達不可直接接 MCU**,必須經馬達驅動器(L9110/TB6612/MOSFET)、獨立電源、
  續流二極體、共地。電路與原理見 [`../../docs/08-PWM.md`](../../docs/08-PWM.md) 的 §8.8。
- 編譯/燒錄(與預設的呼吸燈分開):
  ```bash
  make TARGET=motor_sine         # 編譯 motor_sine.c
  make TARGET=motor_sine flash   # 燒錄
  ```

## 練習
1. 調整 `step_delay()` 讓呼吸變快或變慢。
2. 用第 5 課的 ADC 值當 duty,做成「旋鈕調光器」。
3. 讓 LED 停在固定亮度(例如半亮),不要呼吸。
