# 第 5 課:ADC 類比輸入 — 讀可變電阻的電壓(C 版)

## 這個範例做什麼
讀取 AIN0(P1.7)上可變電阻的電壓,轉成 0~4095 的數字,透過 UART 印到電腦。轉動電阻時數字跟著變。

## 接線
```
可變電阻一端 --> VDD (3.3V)
可變電阻另一端 --> GND
可變電阻中間(可動端)--> P1.7 (AIN0)

UART:P0.6 (TXD) --> USB-TTL 的 RX,GND 共接
```
- 序列埠參數:**9600 8N1**。

## 編譯與燒錄
```bash
make        # 編譯,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
終端機約每 0.3 秒出現一行,轉動電阻時數字在 0~4095 之間變化:
```
ADC demo start (turn the potentiometer)
ADC = 0
ADC = 2047
ADC = 4095
...
```
終端機指令:`picocom -b 9600 /dev/ttyUSB0`(或 `screen /dev/ttyUSB0 9600`)。

## 程式重點
- P1.7 設「僅輸入」模式,並用 `AINDIDS` 禁用該腳的數位輸入(當類比腳)。
- `ADCCON0` 低 4 位選通道(0 = AIN0);`ADCCON1.0` = `ADCEN` 開啟 ADC。
- 讀取流程:清 `ADCF` → 設 `ADCS` 啟動 → 等 `ADCF` → 組合 `(ADCRH<<4)|(ADCRL&0x0F)` 得 12 位元值。
- 電壓 ≈ (ADC值 / 4095) × VDD。原理詳見 [`../../docs/06-ADC類比輸入.md`](../../docs/06-ADC類比輸入.md)。

## 對照另一個版本
→ 組語版:[`../../asm/05-adc/`](../../asm/05-adc/)。讀的是同一個 ADC 值,但 C 印**十進位**(0~4095),組語為求單純印**十六進位**(000~FFF)。

## 練習
1. 把 ADC 值換算成電壓(mV)再印出來。
2. 當電壓超過一半時點亮一顆 LED(做簡單的門檻判斷)。
3. 改讀另一個通道(例如 AIN1 = P3.0),對照 `include/N76E003.h` 與 docs。
