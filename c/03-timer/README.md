# 第 3 課:計時器中斷 — 精準閃爍(C 版)

## 這個範例做什麼
用 Timer0 中斷讓 P1.4 的 LED **每 0.5 秒**精準翻轉一次,而且主程式完全不用管它。

## 接線
```
P1.4 ──► 220Ω ──► LED 長腳(+),LED 短腳(−)──► GND
```
- ⚠️ 板載 LED 極性可能相反,必要時對調。

## 編譯與燒錄
```bash
make        # 編譯,產生 main.hex
make flash  # 燒錄到 N76E003
make clean  # 清除編譯產物
```
> 首次燒錄前,請先完成 [`../../docs/00-環境建置與燒錄.md`](../../docs/00-環境建置與燒錄.md) 的 udev 設定。

## 預期結果
LED 穩定地每 0.5 秒亮/滅切換一次(完整亮滅週期 1 秒),比第 1 課的軟體延時精準得多。

## 程式重點
- Timer0 設 16 位元模式、時脈吃滿 16MHz(`CKCON.T0M=1`);預載值 `0xC180` 讓它每 1ms 溢位。
- 三道中斷閘門都要開:`ET0`(Timer0)、`EA`(總開關)、`TR0`(啟動計時)。
- ISR 用 `__interrupt(1)` 標記(1 = Timer0);ISR 裡每 1ms +1,數滿 500 次翻轉 LED。
- 共享變數 `ms_count` 要加 `volatile`。
- 原理詳見 [`../../docs/04-計時器與中斷.md`](../../docs/04-計時器與中斷.md)。

## 對照另一個版本
→ 組語版:[`../../asm/03-timer/`](../../asm/03-timer/)。C 幫你把 ISR 接上向量、保存暫存器、用 `reti` 返回;組語這些全得自己做,16 位元計數也要用兩個位元組手動湊。

## 練習
1. 改 ISR 的比較值,做成每 0.25 秒閃一次。
2. 在 `while(1)` 裡加第 2 課的讀按鈕,證明中斷與主程式能同時運作。
3. 做一個跑馬燈,讓多顆 LED 輪流亮。
