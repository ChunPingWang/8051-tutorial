# 第 99 章:組合語言 × C 語言 對照速查表

> 這是一張「翻譯對照表」。當你在 C 裡寫下某一行,想知道它在底層(組語)對應什麼;
> 或在讀組語時想知道它相當於哪句 C ── 就查這裡。

---

## 1. 最常見的動作

| 想做的事 | C 語言 | 組合語言 (sdas8051) |
|---------|--------|---------------------|
| 某腳輸出 1 | `P14 = 1;` | `setb P14` |
| 某腳輸出 0 | `P14 = 0;` | `clr P14` |
| 某腳反相 | `P14 = !P14;` | `cpl P14` |
| 讀某腳是否為 0 | `if (P15 == 0)` | `jnb P15, 標籤` |
| 讀某腳是否為 1 | `if (P15 == 1)` | `jb P15, 標籤` |
| 設定某個位元 | `REG \|= (1<<4);` | `orl REG, #0x10` |
| 清除某個位元 | `REG &= ~(1<<4);` | `anl REG, #0xEF` |
| 整個暫存器賦值 | `REG = 0x50;` | `mov REG, #0x50` |

---

## 2. 位元運算(嵌入式最常用)

| 目的 | C | 組語 | 說明 |
|------|---|------|------|
| 設定某些位 | `x \|= mask;` | `orl x, #mask` | OR:要設的位填 1 |
| 清除某些位 | `x &= ~mask;` | `anl x, #~mask` | AND:要清的位填 0 |
| 反相某些位 | `x ^= mask;` | `xrl x, #mask` | XOR |
| 左移 | `x << n` | `rl A` / `clr C` `rlc A` | 一次移 1 位 |
| `(1<<4)` | = `0x10` | `#0x10` | 第 4 位為 1 |

> 小抄:`(1<<n)` 就是「第 n 位是 1」。`~(1<<n)` 就是「只有第 n 位是 0」。

---

## 3. 流程控制

| 結構 | C | 組語的作法 |
|------|---|-----------|
| 無窮迴圈 | `while(1){ }` | `loop: ... sjmp loop` |
| if | `if(cond){A}` | 用 `jb/jnb/jz/jnz/cjne` 判斷後跳過 A |
| if-else | `if(cond){A}else{B}` | 條件跳到 B,A 做完 `sjmp` 跳過 B |
| for 計次 | `for(i=0;i<n;i++)` | `mov R2,#n` … `djnz R2, 標籤` |
| 呼叫函式 | `f();` | `lcall f` |
| 函式返回 | `return;` | `ret` |
| 中斷返回 | (自動) | `reti` |

常用的「判斷並跳」指令:

| 指令 | 意思 |
|------|------|
| `jz / jnz 標籤` | A 為 0 / 不為 0 就跳 |
| `jb / jnb bit,標籤` | 某 bit 為 1 / 為 0 就跳 |
| `jc / jnc 標籤` | 進位旗標 C 為 1 / 0 就跳 |
| `cjne A,#n,標籤` | A 不等於 n 就跳(順便影響 C 旗標) |
| `djnz R,標籤` | R 減 1,結果不為 0 就跳(做迴圈神器) |

## 4. 資料搬移

| 動作 | C | 組語 |
|------|---|------|
| 變數 = 常數 | `a = 5;` | `mov a, #5` |
| 變數 = 變數 | `a = b;` | `mov a, b` |
| 算術加 | `a = b + c;` | `mov A,b` `add A,c` `mov a,A` |
| 帶進位加(多位元組) | — | `addc A, x` |
| 讀程式記憶體(字串/表) | `s[i]`(const) | `movc A, @A+DPTR` |
| 16 位元指標 | `char *p` | `DPTR` |

> 8051 的算術幾乎都要經過累加器 `A`(ACC):先把資料搬到 A,運算,再搬出去。
> C 編譯器自動幫你做這些搬移,這也是 C 好寫的原因之一。

## 5. 中斷

| 項目 | C (SDCC) | 組語 |
|------|----------|------|
| 定義 ISR | `void f() __interrupt(n)` | 在向量位址放 `ljmp f` |
| Timer0 向量 | `__interrupt(1)` | `.org 0x000B` |
| 外部中斷0 | `__interrupt(0)` | `.org 0x0003` |
| 外部中斷1 | `__interrupt(2)` | `.org 0x0013` |
| Timer1 | `__interrupt(3)` | `.org 0x001B` |
| UART | `__interrupt(4)` | `.org 0x0023` |
| 保存現場 | (自動) | 進 ISR `push acc`/`push psw`,出 ISR 前 `pop` |
| 返回 | (自動) | `reti`(不是 `ret`!) |

## 6. 程式骨架對照

**C:**
```c
#include "N76E003.h"

void main(void)
{
    /* 初始化 */
    while (1)
    {
        /* 主迴圈 */
    }
}
```

**組語:**
```asm
    .module 名稱
    ; SFR 位址定義（= 等號）
    P1M2 = 0xB4

    .area CODE (ABS,CODE)
    .org 0x0000
    ljmp start          ; 重置向量
    ; (需要的話) .org 0x000B 放中斷向量

start:
    ; 初始化
main_loop:
    ; 主迴圈
    sjmp main_loop
```

> ⚠️ 本教材用的 SDCC `sdas8051` 有兩個要注意的地方:
> 1. 程式區段用 `.area CODE (ABS,CODE)` 搭配 `.org` 指定絕對位址。
> 2. **不要**在結尾寫 `.end`(這版組譯器不接受它,會報錯)。

---

## 7. SDCC 的特殊關鍵字

| 關鍵字 | 用途 |
|--------|------|
| `__sfr __at(位址)` | 定義一個特殊功能暫存器(見 `include/N76E003.h`)|
| `__sbit __at(位址)` | 定義一個可單獨存取的位元 |
| `__interrupt(n)` | 把函式標記為中斷服務程式 |
| `__xdata` | 變數放到外部 RAM(XRAM) |
| `__code` | 資料放到程式記憶體(唯讀,如字串表) |
| `volatile` | 告訴編譯器此變數隨時會變,勿過度最佳化(中斷共享變數、延時空迴圈必用)|

## 8. 編譯指令速查

| | C | 組語 |
|--|---|------|
| 編譯/組譯 | `sdcc -mmcs51 ... main.c -o main.ihx` | `sdas8051 -plosgff main.asm` |
| 連結 | (sdcc 一併完成) | `sdld -i main.ihx main.rel` |
| 轉 HEX | `packihx main.ihx > main.hex` | `packihx main.ihx > main.hex` |
| 燒錄 | `nuvoprog program -t n76e003 -a main.hex` | 同左 |

平常都包在 `make` / `make flash` 裡,這張表是給你想「手動跑一次看看」時參考。
