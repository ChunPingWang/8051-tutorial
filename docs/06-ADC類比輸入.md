# 第 06 章:ADC 類比輸入(對應第 5 課)

> 對應範例:[`c/05-adc`](../c/05-adc/) 與 [`asm/05-adc`](../asm/05-adc/)
> 目標:讀取一個可變電阻的電壓,把它變成數字,再用 UART 印到電腦上。

---

## 6.1 數位 vs 類比

前面幾課處理的都是**數位**訊號:一支腳不是高(1)就是低(0),只有兩種狀態。

但真實世界是**類比**的:溫度、亮度、聲音、旋鈕轉到一半……這些是「連續變化」的量,
不是非 0 即 1。要讓微控制器讀懂它們,需要 **ADC(Analog-to-Digital Converter,類比轉數位轉換器)**。

**ADC 的工作:把一個電壓,轉換成一個數字。**

---

## 6.2 12 位元是什麼意思?

N76E003 的 ADC 是 **12 位元**的。意思是它把「0V ~ VDD」這段電壓範圍,切成 2¹² = **4096** 格,
用 **0 ~ 4095** 的整數來表示:

| 腳位電壓 | ADC 讀到的值 |
|---------|-------------|
| 0 V(接 GND) | 0 |
| VDD 的一半 | 約 2048 |
| VDD(滿) | 4095 |

反推電壓的公式:
```
電壓 ≈ (ADC值 / 4095) × VDD
```

例如 VDD=3.3V、讀到 2048 → 電壓 ≈ (2048/4095)×3.3 ≈ 1.65V。

> 位元數越多,切得越細、越精準。8 位元只有 256 格,12 位元有 4096 格,解析度高很多。

---

## 6.3 電路:可變電阻當「分壓器」

可變電阻(電位器 / 旋鈕)有三支腳,接法是:

```
  VDD ----[ 可變電阻 10kΩ ]---- GND
                  |
             (中間可動端)
                  |
                  v
             P1.7 (AIN0)
```

- 兩端分別接 VDD 和 GND。
- 中間的可動端接到 **P1.7**。轉動旋鈕時,中間腳的電壓就在 0V ~ VDD 之間連續變化。
- 這種「用電阻把電壓按比例分出來」的接法叫**分壓器 (voltage divider)**。

N76E003 的 ADC 有 8 個輸入通道 AIN0~AIN7,分佈在不同腳位。本課用 **AIN0,它位於 P1.7**。

---

## 6.4 設定 ADC 的三個關鍵動作

對照範例的 `adc_init()`:

```c
// ① 把 P1.7 設成「僅輸入」模式(類比腳要高阻抗,不要驅動電壓)
P1M1 |=  (1 << 7);
P1M2 &= ~(1 << 7);

// ② 選擇通道 + 關掉這支腳的數位輸入
ADCCON0 &= 0xF0;     // ADCCON0 低 4 位 = 通道編號,清成 0 → AIN0
AINDIDS  = 0x00;
AINDIDS |= 0x01;     // 禁用 P1.7 的數位輸入緩衝(當純類比腳)

// ③ 開啟 ADC 電路
ADCCON1 |= 0x01;     // ADCEN = 1
```

重點:
- **類比腳要設成「僅輸入」**,而且**關掉數位輸入**(`AINDIDS`),避免數位緩衝器干擾、也省電。
- `ADCCON0` 的低 4 位是**通道選擇**,想讀別的通道就改這裡。

---

## 6.5 讀一次 ADC:啟動 → 等待 → 取值

```c
unsigned int adc_read(void)
{
    ADCF = 0;                    // 清除「轉換完成」旗標
    ADCS = 1;                    // 啟動一次轉換
    while (ADCF == 0)            // 等硬體轉換完成(ADCF 會自己變 1)
        ;
    return ((unsigned int)ADCRH << 4) | (ADCRL & 0x0F);
}
```

這個「清旗標 → 啟動 → 等旗標 → 讀結果」的節奏,和 UART 的 `TI` 很像,是硬體周邊的通用模式。

### 為什麼結果要 `ADCRH << 4 | ADCRL`?

12 位元的結果塞不進一個 8 位元暫存器,所以拆成兩個:
- `ADCRH`(高):放最高的 8 位
- `ADCRL`(低):只有低 4 位有效

把它們拼回一個 12 位元數字:`(ADCRH 左移 4 位) 再 OR 上 ADCRL 的低 4 位`。

```
  ADCRH =  [ b11 b10 b9 b8 b7 b6 b5 b4 ]
  ADCRL =  [  -   -   -  -  b3 b2 b1 b0 ]
  結果  =  ADCRH<<4 | (ADCRL & 0x0F) = 12 位元完整值
```

## 6.6 組語版的差異:印十進位 vs 十六進位

讀 ADC 的動作,組語和 C 完全一樣(清 `ADCF`、設 `ADCS`、等、讀 `ADCRH/ADCRL`)。
差別只在「怎麼把數字印出來」:

- **C 版**:印成人最習慣的**十進位**(0~4095)。用到除以 10 取餘數的小技巧。
- **組語版**:為了保持單純,印成**十六進位 3 位**(000~FFF)。因為十六進位每 4 位對一個字元,
  不需要做除法,只要把每個 nibble(4 位)查表轉成 `'0'`~`'F'` 即可。

兩者讀的是**同一個 ADC 值**,只是顯示進位不同。這也順便讓你看到:
「把數字顯示成文字」這件看似理所當然的事,在底層其實要寫不少程式。

組語的 nibble 轉字元用查表:
```asm
hextab: .ascii "0123456789ABCDEF"
; A = 0~15 → 查表得到對應字元
put_hex:
    anl   A, #0x0F
    mov   DPTR, #hextab
    movc  A, @A+DPTR
    lcall putc
    ret
```

## 6.7 動手做

- C 版:[`c/05-adc/README.md`](../c/05-adc/README.md)
- 組語版:[`asm/05-adc/README.md`](../asm/05-adc/README.md)

轉動可變電阻,終端機上的數字會跟著在 0~4095(組語版 000~FFF)之間變化。

**練習:**
1. 把 ADC 值換算成電壓(浮點),印出像 `1.650 V` 的字樣。(提示:C 可用浮點,注意程式會變大)
2. 做一個「電壓門檻」:電壓超過一半時點亮 LED(結合第 1 課)。
3. 改讀別的通道(改 `ADCCON0` 低 4 位與對應腳位),例如接光敏電阻做亮度計。
