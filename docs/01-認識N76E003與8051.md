# 第 01 章:認識 N76E003 與 8051

> 這一章不寫程式,先把「我們在對什麼東西下指令」弄清楚。看懂了再寫程式會輕鬆很多。

---

## 1.1 什麼是微控制器 (MCU)?

**微控制器 (Microcontroller, MCU)** 可以想成「一整台縮小到一顆晶片裡的電腦」。
一台電腦有 CPU、記憶體、硬碟、鍵盤滑鼠介面;微控制器把 **CPU + 記憶體 + 輸入輸出腳位** 全部塞進一顆小小的晶片。

它和個人電腦最大的差別:

| | 個人電腦 (PC) | 微控制器 (MCU) |
|---|---|---|
| 用途 | 跑作業系統、各種軟體 | 專心做一件事(控制 LED、馬達、感測器…) |
| 記憶體 | GB 等級 | KB 等級(N76E003 只有 18KB 程式空間) |
| 執行方式 | 開機進作業系統 | 一通電就直接跑你燒進去的程式,永遠跑一個 `while(1)` 迴圈 |
| 和外界互動 | 螢幕、鍵盤 | 直接用「腳位」接 LED、按鈕、感測器 |

**重點觀念:** 微控制器的程式不像手機 App 會「結束」。它一通電就從頭開始跑,跑到一個無窮迴圈後就一直轉,直到斷電。

---

## 1.2 什麼是 8051?

**8051** 是 1980 年由 Intel 推出的一種微控制器「架構 (architecture)」。
架構的意思是「這顆晶片認得哪些指令、內部長什麼樣子」。因為它簡單又好用,幾十年來被無數廠商拿去改良、重做,形成一個龐大的「8051 家族」。

你現在用的 **Nuvoton(新唐)N76E003** 就是 8051 家族的一員。它:

- **指令與傳統 8051 完全相容** → 所以你學到的 8051 知識到處都能用
- 是 **「1T」** 版本 → 速度比老 8051 快很多(見下一節)
- 加了很多現代周邊:精準的計時器、ADC(類比轉數位)、PWM、UART 等

> 所以本教材學的是「8051 的通用知識」+「N76E003 的實作細節」。前者一輩子受用,後者換晶片時再查手冊即可。

---

## 1.3 「1T」是什麼意思?為什麼重要?

老式 8051 執行一個「機器週期」要花 **12 個** 時脈 (clock)。
N76E003 是 **1T**,一個機器週期只要 **1 個** 時脈 → 同樣的頻率下,速度大約快 12 倍。

這件事對你寫程式有個實際影響:**用「空轉迴圈」做延時的時候,圈數要抓比老 8051 多很多**,否則閃爍會快到看不見。這也是為什麼第 3 課我們要改用「計時器 (Timer)」來做精準延時。

N76E003 內建一個 **16 MHz 的振盪器 (HIRC)**,預設就用它當時脈來源,不用外接石英振盪器,接上電就能跑。

---

## 1.4 N76E003 的腳位 (Pinout)

N76E003 常見的是 **20 腳 (TSSOP-20)** 封裝。它的 GPIO(可程式控制的腳位)分成三組「埠 (Port)」:

- **Port 0 (P0.0 ~ P0.7)**
- **Port 1 (P1.0 ~ P1.7)**
- **Port 3 只有 P3.0**;**Port 2 只有 P2.0**(通常當重置腳 /RST,一般不拿來當一般 IO)

每一支腳通常「身兼多職」(這叫 **腳位複用**)。例如:

| 腳位 | 一般用途 | 其他功能 |
|------|---------|----------|
| P0.6 | 數位 IO | UART0 的 **TXD**(傳送)|
| P0.7 | 數位 IO | UART0 的 **RXD**(接收)|
| P1.7 | 數位 IO | ADC 類比輸入通道之一 |
| P2.0 | 數位 IO | **/RST** 重置腳 |

> 到底哪支腳有什麼功能,以 **Nuvoton 官方資料手冊 (Datasheet)** 的 Pin Configuration 為準。寫每一課時我們都會明確告訴你用哪支腳。

---

## 1.5 記憶體:程式放哪?變數放哪?

這是初學者最容易混淆、但**非常重要**的觀念。8051 的記憶體分成好幾種,各有各的用途:

### (1) 程式記憶體 Flash / APROM(放「程式碼」)
- N76E003 有 **18 KB** 的 Flash,叫做 **APROM**。
- 你燒錄進去的程式就住在這裡。**斷電不會消失。**
- 另外還有一小塊 **LDROM**,可放「開機載入程式 (bootloader)」,初學階段先不用管。

### (2) 內部資料記憶體 RAM(放「變數」,斷電消失)
8051 的內部 RAM 有 256 位元組,又細分成:

- **低 128 位元組 (0x00~0x7F)**:一般變數、暫存器庫、堆疊都在這。
  - 其中 **0x20~0x2F** 這 16 位元組是 **「可位元定址區」**:可以單獨對某一個 bit 做讀寫(這就是為什麼 8051 控制 LED 這種「一個腳位 = 一個 bit」的事情特別方便)。
- **高 128 位元組 (0x80~0xFF)**:和「SFR」共用位址空間,用不同的定址方式區分(見下一節)。

### (3) 外部資料記憶體 XRAM
- N76E003 內部另外模擬了 **768 位元組** 的 XRAM,放比較大的陣列時會用到。
- 在 C 裡用 `__xdata` 關鍵字放到這裡。

> **為什麼要分這麼多種?** 因為 8051 誕生在記憶體極度昂貴的年代,設計上錙銖必較。你只要先記住:**程式燒在 Flash(不會消失),變數跑在 RAM(斷電消失)** 就夠了。

---

## 1.6 核心觀念:特殊功能暫存器 (SFR)

這是學 8051 的**關鍵中的關鍵**,一定要懂。

你要怎麼「叫」晶片去做事?例如「把 P1.4 這支腳變成高電位」?
答案是:**寫入一個特定的記憶體位址**。這些「一寫進去就會讓硬體動作」的特殊位址,就叫 **特殊功能暫存器 (Special Function Register, SFR)**。

打個比方:SFR 就像家裡牆上的**各種開關和旋鈕**。

- 想開電燈 → 去撥「電燈開關」(寫 `P14 = 1`)
- 想調冷氣溫度 → 去轉「溫度旋鈕」(設定 Timer 的暫存器)
- 想知道門鈴有沒有被按 → 去看「門鈴指示燈」(讀取某個旗標位元)

每個 SFR 都住在 **0x80 ~ 0xFF** 這段位址,而且**都有一個好記的名字**。例如:

| 名字 | 位址 | 作用 |
|------|------|------|
| `P1`   | 0x90 | Port 1 的 8 支腳,一個 bit 一支腳 |
| `P1M1` / `P1M2` | 0xB3 / 0xB4 | 設定 Port 1 每支腳是「輸入還是輸出」 |
| `TMOD` | 0x89 | 設定計時器的工作模式 |
| `SCON` | 0x98 | 設定 UART 序列埠 |
| `IE`   | 0xA8 | 中斷總開關 |

**本教材的 `include/N76E003.h` 做的事,就是把這些「位址」對應成「名字」**,讓你可以直接寫:

```c
P1M2 |= (1 << 4);   // 而不用寫晦澀的 *(0xB4) |= 0x10;
```

> 記住這句話:**在 8051 上寫程式,大部分時間就是在「設定各種 SFR」。** 看懂手冊裡每個 SFR 的每個 bit 代表什麼,你就會操作這顆晶片了。

---

## 1.7 N76E003 的 GPIO 四種模式

GPIO = General Purpose Input/Output(通用輸入輸出)。N76E003 的每一支腳可以設成 **四種模式**,由 `PxM1`、`PxM2` 兩個暫存器裡**對應的那一個 bit** 共同決定:

| PxM1 的 bit | PxM2 的 bit | 模式 | 白話解釋 | 什麼時候用 |
|:---:|:---:|------|---------|-----------|
| 0 | 0 | **準雙向** Quasi-bidirectional | 預設模式,可讀可寫但輸出電流弱 | 一般用途、接按鈕 |
| 0 | 1 | **推挽輸出** Push-Pull | 強力輸出高/低電位 | **驅動 LED、蜂鳴器** |
| 1 | 0 | **僅輸入** Input-only | 高阻抗,只讀不寫 | 讀類比訊號、純輸入 |
| 1 | 1 | **開漏** Open-Drain | 只能拉低,要外接上拉電阻 | I2C 匯流排等 |

舉例:要把 **P1.4** 設成推挽輸出,就要讓 `P1M1` 的第 4 位 = 0、`P1M2` 的第 4 位 = 1:

```c
P1M1 &= ~(1 << 4);   // P1M1.4 = 0
P1M2 |=  (1 << 4);   // P1M2.4 = 1
```

> 這段程式碼在第 1 課就會用到,先有個印象即可。`(1 << 4)` 代表「第 4 位是 1、其餘是 0」,也就是二進位 `0001 0000`。

---

## 1.8 本章小結

- N76E003 是 **8051 家族** 的現代成員,**1T** 架構速度快,內建 **16MHz** 振盪器。
- 程式燒在 **Flash (APROM, 18KB)**,變數跑在 **RAM**。
- 操作晶片 = **設定 SFR**(住在 0x80~0xFF 的特殊位址,我們用名字稱呼它)。
- 控制一支腳要先用 `PxM1`/`PxM2` 設定它的**模式**,再對 `Px` 讀寫資料。
