## 9.3 N76E003 腳位總表(本教材用到的)

N76E003 是 20 腳封裝。下面只列**本教材會用到**的腳位,完整定義請查 Nuvoton 官方資料手冊。

### 電源與燒錄(接 Nu-Link,固定)

| 腳位名 | 用途 |
|--------|------|
| **VDD** | 電源正極(約 3.3V,由 Nu-Link 供電) |
| **GND** | 接地(所有電路的共同參考點) |
| **P2.0 / RST** | 重置腳(接 Nu-Link,一般不當 IO) |
| **ICPDA / ICPCK** | 燒錄資料/時脈(接 Nu-Link) |

### 訊號腳(接你的零件)

| 腳位 | 本教材用途 | 出現在 | 複用功能 |
|------|-----------|--------|----------|
| **P1.4** | 接 LED(第 7 課是「行人綠燈」) | 第 1、2、3、7 課 | 一般 IO |
| **P1.5** | 接按鈕(第 7 課是「行人按鈕」) | 第 2、7 課 | 一般 IO |
| **P1.2** | 接 LED / 馬達驅動器 | 第 6 課 | **PWM0 輸出** |
| **P0.6** | UART 傳送 → 電腦 | 第 4、5、7 課 | **TXD** |
| **P0.7** | UART 接收 ← 電腦(本教材多半不接) | 第 4、5 課 | **RXD** |
| **P1.7** | 接可變電阻(類比輸入) | 第 5 課 | **ADC 通道 AIN0** |
| **P1.0** | 車道紅燈 | 第 7 課 | 一般 IO |
| **P1.1** | 車道黃燈 | 第 7 課 | 一般 IO |
| **P1.3** | 車道綠燈 | 第 7 課 | 一般 IO |
| **P1.6** | 行人紅燈 | 第 7 課 | 一般 IO |
| **P0.4** | 蜂鳴器(選用) | 第 7 課 | 一般 IO |

> 💡 **為什麼第 6 課 LED 改接 P1.2?** 因為亮度由硬體 **PWM0** 產生,而 PWM0 的輸出腳固定在 P1.2(腳位複用)。其他課的單純開關輸出才用 P1.4。

## 9.4 共通觀念(看一次,受用所有課)

### 共地 (common ground)
只要有**兩個以上的裝置**要互通訊號(晶片 ↔ USB-TTL、晶片 ↔ 馬達驅動器),
它們的 **GND 一定要接在一起**。否則訊號沒有共同的「0V 基準」,會完全不work或讀到亂碼。

### LED 有極性
- **長腳 = 正極 (+)**,接電流進來的那端。
- **短腳 = 負極 (−)**,接 GND。
- 一定要**串一顆電阻**(220Ω)限流,否則 LED 會燒掉。

### 麵包板怎麼用
- 中間區每「一排 5 孔」橫向(或縱向)是相通的,方便把多條線接在同一個節點。
- 兩側的長條(紅/藍)是**電源匯流排**,習慣上紅接 VDD、藍接 GND,方便各處取電。

## 9.5 各課接線圖彙整

> 以下接線圖一律用純文字繪製:`-->` 代表連線方向,`>|` 代表 LED(左為長腳+、右為短腳−)。

### 第 1、3 課:LED 閃爍 / 計時器
```
  P1.4 ----[ 220Ω ]---->|---- GND
                        (LED)
```
`>|` 的左邊接電阻(LED 長腳/正極),右邊接 GND(LED 短腳/負極)。

### 第 2 課:按鈕控制 LED
```
  LED :  P1.4 ----[ 220Ω ]---->|---- GND

  按鈕:  P1.5 ----[ 按鈕 ]---- GND
```
按鈕用晶片內部弱上拉,免外接電阻:放開讀到 1,按下讀到 0。

### 第 4 課:UART 輸出
```
  N76E003 P0.6 (TXD) ----> USB-TTL  RX
  N76E003 GND        ----> USB-TTL  GND     (務必共地)
```
只示範「送」,RXD 可不接;電腦端設 9600 8N1。

### 第 5 課:ADC 讀可變電阻(+ UART 輸出)
```
  VDD ----[ 可變電阻 10kΩ ]---- GND
                  |
             (中間可動端)
                  |
                  v
             P1.7 (AIN0)
```
可變電阻兩端接 VDD/GND,中間可動端接 P1.7。另加第 4 課的 UART 接線
(P0.6 --> RX、GND --> GND)把讀到的值印出來。

### 第 6 課:PWM 呼吸燈
```
  P1.2 ----[ 220Ω ]---->|---- GND
```
LED 接 P1.2(不是 P1.4),因為亮度由 PWM0 產生、其輸出腳固定在 P1.2。

### 第 6 課【進階】:正弦加減速直流馬達
```
  馬達電源(+5V~+12V) ----+
                         |
  P1.2 (PWM) ---->  [ 馬達驅動器 / MOSFET ]  ---->  馬達(M) ----+
                         |                                      |
                    (與 MCU 共地)                   續流二極體(並聯馬達)
                         |                                      |
                        GND ------------------------------------+
```
> ⚠️ **馬達絕對不可直接接 MCU 腳位**!必經驅動器、獨立電源、續流二極體、共地。
> 詳見 [`08-PWM.md`](08-PWM.md) 的 §8.8。

### 第 7 課:狀態機(行人穿越號誌)
```
  車道紅燈  P1.0 ----[ 220Ω ]---->|---- GND
  車道黃燈  P1.1 ----[ 220Ω ]---->|---- GND
  車道綠燈  P1.3 ----[ 220Ω ]---->|---- GND
  行人紅燈  P1.6 ----[ 220Ω ]---->|---- GND
  行人綠燈  P1.4 ----[ 220Ω ]---->|---- GND

  行人按鈕  P1.5 ----[ 按鈕 ]---- GND          (內部弱上拉,按下讀到 0)
  蜂鳴器    P0.4 ---- 有源蜂鳴器 ---- GND      (選用)

  UART      P0.6 (TXD) ----> USB-TTL  RX
            GND        ----> USB-TTL  GND      (務必共地)
```
- 每顆 LED 都要**各自**串一顆 220Ω,不可共用一顆。
- 💡 **零件不夠?** 只接「行人綠燈 P1.4 + 按鈕 P1.5 + UART」就看得懂整個流程,
  其餘燈號看 UART 印出的狀態轉移紀錄即可。
- 💡 **完全沒零件?** 這一課附了電腦模擬器,在專案根目錄下 `make sim` 就能跑完,
  連開發板都不需要。詳見 [`11-狀態機.md`](11-狀態機.md)。
- 組語版的接線完全相同,所以**接好一次,C 版與組語版可以輪流燒**。
  組語精簡版(`asm/07-fsm/main.asm`)不用蜂鳴器與 UART,只要 5 顆 LED + 按鈕。

## 9.6 安全與常見錯誤

| 千萬不要 | 原因 |
|---------|------|
| LED 不串電阻直接接 | 電流過大,燒 LED、甚至傷腳位 |
| 馬達/繼電器等直接接 MCU 腳 | 電流過大 + 反電動勢,**燒晶片** |
| 用 MCU 的 3.3V 去帶馬達 | 供電不足,電壓塌陷導致重置 |
| 忘了共地 | 訊號無基準,UART 亂碼、感測值亂跳 |
| 用 5V 的 USB-TTL 直接接 3.3V 腳 | 可能超過耐壓;請用 3.3V 版或加準位轉換 |
| 燒錄線 VDD/GND 接反 | 可能損壞開發板 |
