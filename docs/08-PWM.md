# 第 08 章:PWM 脈衝寬度調變(對應第 6 課)

> 對應範例:[`c/06-pwm`](../c/06-pwm/) 與 [`asm/06-pwm`](../asm/06-pwm/)
> 目標:用硬體 PWM 控制 LED 的**亮度**,做出平滑的「呼吸燈」效果。

---

## 8.1 問題:數位腳只有 0 和 1,怎麼做出「半亮」?

前面學的 GPIO 輸出只有兩種狀態:高(亮)或低(滅)。那要怎麼讓 LED「亮一半」?

答案是 **PWM(Pulse Width Modulation,脈衝寬度調變)**:
不是把電壓調成一半,而是讓腳位**非常快速地開、關、開、關**,靠「開的時間佔多少比例」來決定平均亮度。

因為切換快到每秒數百次,眼睛看不出閃爍,只感覺到一個穩定的亮度。

---

## 8.2 兩個關鍵名詞:週期與工作週期

```
   一個週期 (period)
   │◄────────────-->│
   ┌────────┐        ┌────────┐
   │  開 ON │  關 OFF│  開 ON │ ...
   ┘        └────────┘        └──
   │◄───-->│
    工作週期 (duty)
```

- **週期 (period)**:一次「開+關」合起來多長。決定 PWM 的**頻率**。
- **工作週期 (duty cycle)**:一個週期裡「開」佔的比例,通常用百分比或 0~255 表示。
  - duty = 0 → 一直關 → LED 全暗
  - duty = 128(約 50%)→ 半亮
  - duty = 255 → 幾乎一直開 → LED 全亮

**控制亮度 = 控制 duty。** 這就是呼吸燈的全部祕密:把 duty 從 0 慢慢加到 255(漸亮),再慢慢減回 0(漸暗),不斷循環。

> PWM 的用途遠不只 LED 調光:控制馬達轉速、伺服機角度、喇叭音量、電源管理……都靠它。

---

## 8.3 N76E003 的硬體 PWM

好消息:我們**不必**用軟體辛苦地手動開關腳位。N76E003 內建硬體 PWM,
你只要設好「週期」和「工作週期」,它就會自動不停地產生波形,完全不佔用 CPU。

N76E003 有 6 個 PWM 通道(PWM0~PWM5),每個通道固定對應某些腳位。本課用
**PWM0,它可以輸出到 P1.2**:

| 通道 | 輸出腳位 | 啟用方式 |
|------|---------|----------|
| PWM0 | **P1.2** | `PIOCON0 \|= 0x01` |
| PWM1 | P1.1 | `PIOCON0 \|= 0x02` |
| PWM2 | P1.0 | `PIOCON0 \|= 0x04` |
| PWM3 | P0.0 | `PIOCON0 \|= 0x08` |
| PWM4 | P0.1 | `PIOCON0 \|= 0x10` |
| PWM5 | P0.3 | `PIOCON0 \|= 0x20` |

> 所以這一課 LED 要接 **P1.2**(不是前幾課的 P1.4)—— 因為亮度是由 PWM0 這個硬體通道產生的,而它的輸出腳就在 P1.2。

## 8.4 設定步驟

對照範例的 `pwm_init()`:

```c
P1M1 &= ~(1<<2);  P1M2 |= (1<<2);   // ① P1.2 設推挽輸出
PWMCON0 = 0x00;                     // ② 清空主控制暫存器
PWMCON1 = 0x07;                     // ③ PWM 時脈 = Fsys/128,邊緣對齊、獨立模式
PNP     = 0x00;                     // ④ 輸出極性正常(duty 大 = 高電位久 = 亮)
PIOCON0 = 0x01;                     // ⑤ 把 PWM0 接到 P1.2
PWMPH = 0x00; PWMPL = 0xFF;         // ⑥ 週期 = 255+1 = 256 階
PWM0H = 0x00; PWM0L = 0x00;         // ⑦ 初始工作週期 = 0(全暗)
LOAD = 1;                           // ⑧ 載入上面設定
PWMRUN = 1;                         // ⑨ 啟動 PWM!
```

### 頻率怎麼算?

```
PWM 頻率 = PWM時脈 / 週期階數 = (Fsys / 128) / 256 = (16MHz / 128) / 256 ≈ 488 Hz
```

488Hz 遠快過眼睛能分辨的程度(人眼大約 50Hz 以上就看不出閃爍),所以看起來是穩定的亮度。

---

## 8.5 改變亮度:改 duty + LOAD

設定好之後,調亮度只要改工作週期,再按一次「載入」:

```c
void pwm_set_duty(unsigned char duty)
{
    PWM0H = 0x00;
    PWM0L = duty;        // 0~255
    LOAD  = 1;           // 讓新值在下一個週期生效(硬體會自動把 LOAD 清掉)
}
```

呼吸燈的主迴圈就是不斷地加、減 duty:

```c
while (1) {
    for (d = 0;   d <= 255; d++) { pwm_set_duty(d); step_delay(); }  // 漸亮
    for (d = 255; d >  0;   d--) { pwm_set_duty(d); step_delay(); }  // 漸暗
}
```

`step_delay()` 控制每一階停留多久,也就決定「呼吸」的快慢。

## 8.6 C 與組語對照

這一課 C 與組語的設定幾乎逐行對應:

| 做的事 | C | 組語 |
|--------|---|------|
| 設時脈/模式 | `PWMCON1 = 0x07;` | `mov PWMCON1, #0x07` |
| 選輸出腳 | `PIOCON0 = 0x01;` | `mov PIOCON0, #0x01` |
| 設週期 | `PWMPL = 0xFF;` | `mov PWMPL, #0xFF` |
| 設工作週期 | `PWM0L = duty;` | `mov PWM0L, A` |
| 載入生效 | `LOAD = 1;` | `setb LOAD` |
| 啟動 | `PWMRUN = 1;` | `setb PWMRUN` |

差別只在「duty 的迴圈」:C 用 `for`,組語用 `inc`/`dec` 配 `jnz`(見範例註解)。

## 8.8 進階應用:用正弦曲線控制直流馬達轉速

> 對應範例:[`c/06-pwm/motor_sine.c`](../c/06-pwm/motor_sine.c) 與
> [`asm/06-pwm/motor_sine.asm`](../asm/06-pwm/motor_sine.asm)

呼吸燈學會了,我們把同一招用到**直流馬達**上:讓轉速依**正弦曲線**平滑地加速、減速、
再加速,像海浪一樣起伏。這在實務上很有用 —— 平滑的加減速能減少機構衝擊、延長壽命。

### 可行嗎?可行,而且 PWM 正是標準做法

直流馬達的轉速正比於它拿到的**平均電壓**,而 PWM 的 duty 正好決定平均電壓。
所以「改 duty」就是「改轉速」,和調 LED 亮度是同一件事。

為什麼用**正弦**曲線特別好?因為正弦在最高點、最低點的斜率都是 0,
轉速到達兩端時是「漸漸」轉向,不會突然加速或急停,對齒輪、皮帶、負載都更溫柔。

### ⚠️ 硬體:馬達絕對不能直接接 MCU!

這點攸關晶片生死,務必做到:

- 直流馬達**電流大**(常數百 mA 到數 A),遠超過 MCU 腳位能提供的幾 mA。
- 馬達是**感性負載**,開關瞬間會產生反電動勢突波,直接接會打穿晶片。

正確接法是透過**馬達驅動器**(擇一):

```
  馬達電源(+5V~+12V) ----+
                         |
  P1.2 (PWM) ---->  [ 馬達驅動器 / MOSFET ]  ---->  馬達(M) ----+
                         |                                      |
                    (與 MCU 共地)                   續流二極體(並聯馬達)
                         |                                      |
                        GND ------------------------------------+
```

- **驅動器**:初學最簡單用現成模組,如 **L9110S**、**TB6612FNG**、**DRV8833**;
  或進階一點用一顆 **N-channel MOSFET**(閘極接 P1.2,汲極接馬達,源極接地)。
- **續流二極體 (flyback diode)**:並聯在馬達兩端,吸收突波。用驅動 IC 的話多半已內建。
- **獨立電源**:馬達由自己的電源供電,**不要**用 MCU 的 3.3V 去帶馬達。
- **共地**:MCU 的 GND 和馬達電源的 GND 一定要接在一起,PWM 訊號才有參考點。

### 軟體:正弦查表法

8051 沒有硬體浮點、算 `sin()` 很慢,所以我們**事先用電腦算好一張正弦查表**(存在程式
記憶體裡),執行時只要「查表」即可,又快又省:

```c
__code const unsigned char sine_table[64] = {
    128, 140, 152, 165, ... /* 一個完整正弦週期,值 0~255 */
};
```

主迴圈就是不斷地「取下一個表值當 duty」:

```c
while (1) {
    pwm_set_duty( scale_duty(sine_table[idx]) );  // 依正弦設定轉速
    idx = (idx + 1) % 64;
    step_delay();            // 決定加減速快慢
}
```

### 兩個實務細節

1. **最低啟動轉速**:duty 太小時,馬達因靜摩擦根本不會轉。範例用 `MIN_DUTY` 把正弦值
   壓縮到例如 `[40, 255]`,讓它始終轉動、但轉速仍依正弦起伏。你可以依你的馬達實測調整。
2. **加減速快慢**:由 `step_delay()` 的長短決定。想要一個完整起伏花多久,就調這裡。

### C 與組語版的小差異

- **C 版**:用「0~255 的正弦表」+ 執行時 `scale_duty()` 壓縮到 `[40,255]`。
- **組語版**:為了省去乘除運算,直接改用「已經壓縮成 40~255 的正弦表」查表。
  兩者輸出的轉速曲線完全相同,只是把「壓縮」這一步從執行時搬到了事前。

> 想做「單次軟啟動/軟停止」而非連續起伏?把查表只走**前半個週期**(index 0→31,
> duty 由中段升到最大再回落),或改用「只上升的 S 曲線」即可。
