# 第 10 章:系統架構圖(C4 Model)

> 這一章用 [C4 Model](https://c4model.com/) 的分層方式,搭配 **Mermaid** 圖,
> 從「最外層的整體情境」一路畫到「晶片內部的元件」,幫你建立對整個系統的全貌感。
>
> C4 由外而內分四層:**Context(情境)→ Container(容器)→ Component(元件)→ Code(程式碼)**。
> 本章呈現前三層,最細的 Code 層就是各課的原始碼本身。
>
> 📌 這些圖使用 Mermaid 繪製,GitHub 與 VS Code(裝 Mermaid 外掛)皆可直接顯示。
> C4 圖(10.1~10.3)需要支援 C4 的 Mermaid 版本;萬一你的檢視器沒顯示,可改看
> 10.4~10.6 以一般 flowchart / 時序圖繪製的圖,它們涵蓋相同的系統結構與觀念。

## 10.1 Level 1 — 系統情境圖 (System Context)

**看點**:誰在用這個系統?它和外界(開發電腦、燒錄器、周邊、使用者)怎麼互動?

## 10.2 Level 2 — 容器圖 (Container)

**看點**:把「開發電腦」和「N76E003 晶片」各自拆開,看裡面有哪些主要組成,以及
一支程式從原始碼變成晶片裡執行的程式,中間經過哪些「容器」。

```mermaid
C4Container
    title 第二層:容器圖 — 從原始碼到晶片執行

    Person(learner, "學習者", "")

    Container_Boundary(pc, "開發電腦") {
        Container(src, "原始碼", "C / 組語", "main.c、main.asm、N76E003.h")
        Container(toolchain, "SDCC 工具鏈", "sdcc / sdas8051 / sdld / packihx", "編譯、組譯、連結成 .hex")
        Container(nuvoprog, "nuvoprog", "燒錄工具", "把 .hex 透過 Nu-Link 寫入")
        Container(term, "序列埠終端機", "picocom / screen", "顯示晶片送來的訊息")
    }

    Container_Ext(nulink, "Nu-Link", "ICE 燒錄器")

    Container_Boundary(chip, "N76E003 晶片") {
        Container(aprom, "APROM", "18KB Flash", "存放燒入的程式,斷電不失")
        Container(core, "8051 核心", "1T CPU", "逐條執行程式") 
        Container(periph, "硬體周邊", "GPIO/Timer/UART/ADC/PWM", "由程式透過 SFR 操控")
    }

    Rel(learner, src, "編輯")
    Rel(src, toolchain, "make")
    Rel(toolchain, nuvoprog, "產生 main.hex")
    Rel(nuvoprog, nulink, "USB")
    Rel(nulink, aprom, "ICP 寫入")
    Rel(core, aprom, "讀取並執行")
    Rel(core, periph, "讀寫 SFR")
    Rel(periph, term, "UART 傳送", "透過 USB-TTL")
```

## 10.3 Level 3 — 元件圖 (Component)

**看點**:聚焦在「韌體程式」與「晶片周邊」兩塊,看我們的程式由哪些邏輯元件組成,
它們又各自對應到哪個硬體周邊(以及背後的 SFR)。

```mermaid
C4Component
    title 第三層:元件圖 — 韌體程式 × 硬體周邊

    Container_Boundary(fw, "韌體程式 (APROM)") {
        Component(main, "main()", "進入點", "初始化 + while(1) 主迴圈")
        Component(init, "初始化程式", "setup", "設定 GPIO 模式、Timer、UART、ADC、PWM")
        Component(isr, "中斷服務程式", "ISR", "Timer0 溢位時自動執行")
        Component(util, "工具函式", "helper", "延時、uart_putc、查表等")
    }

    Container_Boundary(hw, "N76E003 硬體周邊") {
        Component(gpio, "GPIO", "P0/P1/P3", "PxM1/PxM2 模式 + 資料")
        Component(timer, "Timer0/1", "計時器", "TMOD/TCON/THx/TLx")
        Component(uart, "UART0", "序列埠", "SCON/SBUF + Timer1 鮑率")
        Component(adc, "ADC", "12 位元", "ADCCON0/1 + ADCRH/RL")
        Component(pwm, "PWM", "6 通道", "PWMCON + PWMnH/L + PIOCON0")
    }

    Rel(main, init, "開機呼叫一次")
    Rel(main, util, "主迴圈呼叫")
    Rel(init, gpio, "設模式")
    Rel(init, timer, "設模式/啟動")
    Rel(init, uart, "設鮑率")
    Rel(init, adc, "選通道/啟用")
    Rel(init, pwm, "設週期/啟動")
    Rel(timer, isr, "溢位觸發")
    Rel(isr, gpio, "翻轉腳位")
    Rel(util, uart, "送字元")
    Rel(util, adc, "讀結果")
    Rel(util, pwm, "設 duty")
```

> 對應關係:每一課其實就是在練習「`init` 設定某個周邊 → `main`/`isr` 操作它」。
> 例如第 3 課 = 設定 Timer0 + 寫 Timer0 的 ISR;第 6 課 = 設定 PWM + 在主迴圈改 duty。
>
> 📌 第 7 課則把這個骨架再往上抽一層:中間多一塊**完全不碰硬體的狀態機**,
> 變成「輸入層 → 狀態機 → 輸出層」三層。那張圖與理由見
> [`11-狀態機.md`](11-狀態機.md) §11.5。

## 10.4 補充圖 A:建置與燒錄工具鏈(flowchart)

一支程式從原始碼到在晶片上跑,經過的每一關:

```mermaid
flowchart LR
    subgraph C[C 語言路線]
        c1[main.c] -->|sdcc| c2[main.ihx]
    end
    subgraph A[組合語言路線]
        a1[main.asm] -->|sdas8051| a2[main.rel] -->|sdld| a3[main.ihx]
    end
    c2 --> p[packihx]
    a3 --> p
    p --> hex[main.hex]
    hex -->|nuvoprog program -c FFFFFFFF| nl[Nu-Link]
    nl -->|ICP| chip[(N76E003 APROM)]
    chip -->|自動重置| run[程式開始執行]
```

## 10.5 補充圖 B:韌體執行流程(flowchart)

幾乎每一課的程式都是這個骨架 —— 開機初始化一次,然後永遠跑主迴圈;
有用到中斷的課(如第 3 課),中斷會「插隊」執行 ISR 再回到主迴圈:

```mermaid
flowchart TD
    start([上電 / 重置]) --> vec["跳到 0x0000<br/>(重置向量)"]
    vec --> init[初始化:設定周邊 SFR]
    init --> loop{主迴圈 while 1}
    loop --> work[做事:讀輸入/送 UART/改 duty...]
    work --> loop

    irq{{"中斷事件<br/>(如 Timer0 溢位)"}} -.打斷.-> isr[執行 ISR]
    isr -.reti 返回.-> loop
    loop -.->|中斷隨時可能發生| irq
```

## 10.6 給初學者的四張理解圖

下面這幾張圖,專門用來打通初學最容易卡住的觀念。

### A. 課程學習地圖 — 六課怎麼堆疊上去

每一課都在前一課的基礎上多學一項能力,最後能組合成綜合專題:

```mermaid
flowchart LR
    L1["第1課 LED 閃爍<br/>GPIO 輸出"] --> L2["第2課 按鈕<br/>GPIO 輸入"]
    L2 --> L3["第3課 計時器中斷<br/>Timer / 中斷"]
    L3 --> L4["第4課 UART<br/>序列通訊 / 除錯"]
    L4 --> L5["第5課 ADC<br/>讀類比值"]
    L5 --> L6["第6課 PWM<br/>類比輸出 / 調光調速"]
    L6 --> CAP["綜合專題<br/>旋鈕調速馬達、電壓計…"]
```

> 輸出(1課)→ 輸入(2課)→ 時間(3課)→ 通訊(4課)→ 類比讀(5課)→ 類比控(6課)。
> 六項湊齊,幾乎能做出任何感測+控制的小專案。

### B. N76E003 記憶體地圖 — 程式與變數各住哪裡

這是初學最容易混的觀念:**程式燒在 Flash(不會消失),變數跑在 RAM(斷電消失)**。

```mermaid
flowchart TB
    subgraph CODE["程式記憶體(Flash,斷電保留)"]
        APROM["APROM 18KB<br/>你燒進去的程式"]
        LDROM["LDROM(選用)<br/>開機載入程式"]
    end
    subgraph DATA["資料記憶體(斷電消失)"]
        IRAM["內部 RAM 256B<br/>變數、堆疊"]
        BITA["其中 0x20–0x2F<br/>可單獨存取每個 bit"]
        XRAM["XRAM 768B<br/>放較大的陣列"]
    end
    subgraph SFR["SFR 0x80–0xFF — 控制周邊的『開關面板』"]
        G["P0/P1/P3<br/>PxM1/PxM2"]
        TT["TMOD/TCON<br/>THx/TLx"]
        UU["SCON/SBUF"]
        AA["ADCCON/ADCRx"]
        PP["PWMCON/PWMnH-L"]
    end
```

### C. GPIO 模式決策圖 — PxM1 / PxM2 怎麼決定一支腳

一支腳要設成哪種模式,由 `PxM1`、`PxM2` 對應那一位共同決定。照這張圖走就對了:

```mermaid
flowchart TD
    start["要設定某一支腳 Px.n"] --> q1{"PxM1 的第 n 位 = ?"}
    q1 -->|0| q2{"PxM2 的第 n 位 = ?"}
    q1 -->|1| q3{"PxM2 的第 n 位 = ?"}
    q2 -->|0| m1["準雙向<br/>一般用途、接按鈕(有內部弱上拉)"]
    q2 -->|1| m2["推挽輸出<br/>驅動 LED、蜂鳴器"]
    q3 -->|0| m3["僅輸入<br/>類比輸入、純讀取"]
    q3 -->|1| m4["開漏<br/>I2C 等匯流排(需外部上拉)"]
```

### D. 中斷互動時序圖 — main 與 ISR 怎麼「同時」工作

第 3 課最難想像的就是「中斷」。這張時序圖把 main、計時器硬體、ISR 的互動畫出來:

```mermaid
sequenceDiagram
    participant M as 主程式 main()
    participant T as Timer0 硬體
    participant I as ISR(中斷程式)

    M->>M: 初始化、啟動 Timer0、開啟中斷(EA/ET0)
    M->>M: 進入 while(1) 主迴圈,做自己的事
    loop 背景自動進行
        T->>T: 時脈來一下就 +1
    end
    T-->>I: 數滿溢位!自動跳到向量 0x000B
    Note over M,I: 主程式被「暫停」在原地
    I->>I: 重載預載值、計數、翻轉 LED
    I-->>M: reti 返回剛剛被打斷的地方
    M->>M: 若無其事地繼續跑主迴圈
```

> 關鍵體會:main 和 ISR 看起來像「同時」在跑 —— 計時交給硬體 Timer,時間到才用中斷
> 叫一下 CPU。這就是嵌入式能一邊閃燈、一邊讀按鈕、一邊送 UART 的祕訣。

## 10.7 小結

- **Context**:學習者透過開發電腦 + Nu-Link,把程式送進 N76E003,晶片再去控制周邊、回傳訊息。
- **Container**:原始碼經 SDCC → `.hex` → nuvoprog → Nu-Link → APROM;晶片核心讀 APROM 執行、操控周邊。
- **Component**:韌體的 `main / init / isr / util` 透過 SFR 操作 GPIO/Timer/UART/ADC/PWM 各周邊。

把這三張圖記在腦中,再回頭看每一課的程式,就會很清楚「這段碼在整個系統的哪個位置」。
