# 第 04 章:計時器 (Timer) 與中斷 (Interrupt)(對應第 3 課)

> 對應範例:[`c/03-timer`](../c/03-timer/) 與 [`asm/03-timer`](../asm/03-timer/)
> 目標:用「計時器中斷」讓 LED **精準地** 每 0.5 秒翻轉一次,而且 CPU 同時還能做別的事。

這一章是整個教材觀念上最關鍵的一章。學會中斷,你就從「玩具程式」進入「真正的嵌入式思維」。

---

## 4.1 回顧:軟體延時的兩個大問題

第 1 課用「空轉迴圈」做延時,它有兩個致命缺點:

1. **不精準**:延多久取決於迴圈圈數、編譯器、晶片速度,你很難讓它「剛好 1 秒」。
2. **卡住 CPU**:延時那段時間,CPU 什麼都不能做,只能空轉。如果你還想同時讀按鈕、送資料,就做不到。

這一章用兩個硬體功能來徹底解決:**計時器** 負責精準數時間,**中斷** 負責讓 CPU 不用一直盯著它。

---

## 4.2 計時器 (Timer) 是什麼?

**計時器就是一個會自己「+1」的計數器。** 你給它一個時脈,它每來一個時脈脈衝就自動加 1,完全不需要 CPU 插手。

N76E003 的 Timer0 是 **16 位元** 的,所以它從 0 數到 65535(0xFFFF),再加 1 就會「溢位 (overflow)」變回 0,同時舉起一面小旗子(`TF0` 旗標)說:「我數滿了!」

### 它一秒數幾下?(時脈來源)

計時器的時脈來自系統頻率 **Fsys**。N76E003 開機預設用內建的 **16 MHz** 振盪器,所以 Fsys = 16,000,000 Hz。

Timer0 的時脈可以選兩種(由 `CKCON` 的 `T0M` 位元決定):

| `CKCON.T0M` | Timer0 時脈 | 每數一下的時間 |
|:---:|---|---|
| 0(預設,相容老 8051)| Fsys / 12 ≈ 1.33 MHz | 0.75 µs |
| 1 | Fsys(16 MHz)| 0.0625 µs |

本教材選 **T0M = 1**(用完整的 16 MHz),因為 16,000,000 是個「整數」,拿來算精準時間很方便。

---

## 4.3 怎麼算出「要數幾下 = 多久」?

公式只有一條:

```
要數的次數 = 想要的時間 ÷ 每數一下的時間
```

我們想要每 **1 毫秒 (1ms)** 讓計時器溢位一次。1ms = 1000µs,每下 0.0625µs:

```
要數的次數 = 1000 µs ÷ 0.0625 µs = 16000 (下)
```

但計時器溢位是從「數到 65536」才發生,不是從 0。所以我們不要讓它從 0 開始,而是先**預先塞一個起跑值**,讓它只要再數 16000 下就溢位:

```
預載值 (reload) = 65536 − 16000 = 49536 = 0xC180
```

把 0xC180 拆成高、低位元組,分別放進 `TH0`、`TL0`:

```c
TH0 = 0xC1;    // 高位元組 (49536 >> 8)
TL0 = 0x80;    // 低位元組 (49536 & 0xFF)
```

這樣計時器**每 1ms 溢位一次**,誤差極小(因為 16000 是整數,完全沒有小數誤差)。

> 🧮 **想要別的時間?** 只要改「想要的時間」代進公式即可。注意 16 位元計時器一次最多數 65536 下 = 65536×0.0625µs ≈ **4.1ms**。想要更久(例如 0.5 秒),就讓它「溢位很多次再動作」—— 這正是下一節中斷要做的事。

---

## 4.4 中斷 (Interrupt) 是什麼?

想像你在看書(主程式在跑主迴圈),同時在等水煮開。有兩種做法:

- **輪詢 (polling)**:每隔幾秒就跑去廚房看一下水開了沒 —— 你沒辦法專心看書。
- **中斷 (interrupt)**:裝一個「水開了會叫的水壺」。你專心看書,水一開,鈴聲**打斷**你,你去關火,然後**回到剛剛看書的地方**繼續。

中斷就是第二種做法。當某個事件發生(計時器溢位、按鈕按下、UART 收到資料…),硬體會:

1. **暫停** 目前正在跑的主程式,
2. 自動跳去執行一段你事先寫好的「中斷服務程式 (ISR, Interrupt Service Routine)」,
3. ISR 做完後,**自動回到** 主程式剛剛被打斷的地方,好像什麼都沒發生。

好處是:**CPU 平常可以做自己的事,事件發生時才被叫去處理一下。** 這就是嵌入式系統高效運作的祕訣。

### 中斷向量 (Interrupt Vector)

每種中斷都有固定的「報到位址」,叫中斷向量。8051 常見的有:

| 中斷來源 | 向量位址 | SDCC 的中斷編號 |
|---------|:-------:|:-------:|
| 外部中斷 0 | 0x0003 | 0 |
| **Timer0** | **0x000B** | **1** |
| 外部中斷 1 | 0x0013 | 2 |
| Timer1 | 0x001B | 3 |
| UART | 0x0023 | 4 |

事件一發生,CPU 就自動跳到對應的向量位址去執行。

## 4.5 要開哪些開關?(中斷的三道閘門)

中斷預設是**關閉**的,要讓 Timer0 中斷能動,必須打開三道閘門:

```c
TMOD = 0x01;        // ① Timer0 設為「模式1 = 16位元」
CKCON |= 0x08;      // ② T0M=1,Timer0 用完整 16MHz
TH0 = 0xC1;         //    預載值高位
TL0 = 0x80;         //    預載值低位
ET0 = 1;            // ③-a 開啟「Timer0 中斷」這道閘門
EA  = 1;            // ③-b 開啟「總中斷」這個主開關
TR0 = 1;            // ④ 啟動 Timer0 開始數
```

- **`EA`(總開關)** 像家裡的「總電源」,它一關,所有中斷都失效。
- **`ET0`(分開關)** 是「Timer0 中斷」這一路的開關。
- 兩個都要開,中斷才會發生。這是初學者最常忘記的地方!

---

## 4.6 中斷服務程式 (ISR) 怎麼寫?

在 C(SDCC)裡,用 `__interrupt(編號)` 標記一個函式,它就會變成 ISR:

```c
unsigned int count = 0;      // 記錄溢位了幾次

void timer0_isr(void) __interrupt(1)   // 1 = Timer0
{
    TH0 = 0xC1;              // 重新裝填預載值,下一次才會也是 1ms
    TL0 = 0x80;

    count++;
    if (count >= 500)        // 1ms × 500 = 500ms
    {
        count = 0;
        LED = !LED;          // 翻轉 LED
    }
}
```

重點:

- **ISR 要盡量短**。只做最必要的事(這裡只是計數、翻轉),把複雜運算留給主程式。
- **16 位元模式下,溢位後計時器會從 0 重數**,所以 ISR 裡要**手動重新裝填** `TH0`/`TL0`,否則下一個週期會變成完整的 4.1ms。
- 用到的共享變數(如 `count`、`LED`)要留意主程式也可能動它(進階主題:`volatile`)。

這樣一來,**主程式的 `while(1)` 裡可以空空如也,或去做別的事**,LED 翻轉完全由中斷在背景精準進行。

## 4.7 組語版:中斷向量要自己擺

C 幫你把 ISR 接到向量上,組語就得親手做。做法是在向量位址 **0x000B** 放一行「跳到我的 ISR」:

```asm
    .org 0x0000
    ljmp  start           ; 開機 → 跳到主程式

    .org 0x000B           ; Timer0 中斷向量
    ljmp  timer0_isr      ; 中斷發生 → 跳到 ISR

    .org 0x0100
start:
    ; ... 初始化,和 C 版一模一樣的設定 ...

timer0_isr:
    push acc              ; 進 ISR 先保護會用到的暫存器
    push psw
    mov  TH0, #0xC1       ; 重新裝填預載值
    mov  TL0, #0x80
    ; ... 計數、翻轉 LED ...
    pop  psw              ; 還原暫存器
    pop  acc
    reti                  ; 用 reti(不是 ret!)回到主程式
```

兩個組語重點:

1. **ISR 開頭要 `push` 保存、結尾要 `pop` 還原**用到的暫存器(ACC、PSW 等)。因為你「打斷」了主程式,不能把它正在用的暫存器弄亂。C 編譯器會自動幫你做這件事。
2. **ISR 結尾用 `reti` 而不是 `ret`**。`reti` 除了返回,還會通知中斷系統「我處理完了,可以接受下一個中斷」。用錯會導致之後再也收不到中斷。

---

## 4.8 C 與組語對照總表

| 做的事 | C 語言 | 組合語言 |
|--------|--------|----------|
| 設 Timer0 模式1 | `TMOD = 0x01;` | `mov TMOD, #0x01` |
| 用 16MHz 時脈 | `CKCON \|= 0x08;` | `orl CKCON, #0x08` |
| 裝預載值 | `TH0=0xC1; TL0=0x80;` | `mov TH0,#0xC1` / `mov TL0,#0x80` |
| 開 Timer0 中斷 | `ET0 = 1;` | `setb ET0` |
| 開總中斷 | `EA = 1;` | `setb EA` |
| 啟動計時器 | `TR0 = 1;` | `setb TR0` |
| 定義 ISR | `... __interrupt(1)` | `.org 0x000B` + `ljmp` |
| 從 ISR 返回 | (自動) | `reti` |
