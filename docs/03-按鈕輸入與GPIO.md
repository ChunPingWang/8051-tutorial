# 第 03 章:按鈕輸入(對應第 2 課)

> 對應範例:[`c/02-button`](../c/02-button/) 與 [`asm/02-button`](../asm/02-button/)
> 目標:按下按鈕時 LED 亮,放開時 LED 滅。學會「讀取」一支腳的狀態。

---

## 3.1 從「輸出」到「輸入」

第 1 課我們讓腳位「輸出」訊號去控制 LED。這一課反過來:讓腳位「輸入」—— 去**讀取**外界(按鈕)的狀態。

這一課會同時用到兩支腳:

- **P1.4**:輸出,接 LED(和第 1 課一樣)
- **P1.5**:輸入,接按鈕

---

## 3.2 電路:按鈕怎麼接?有個陷阱

一個按鈕就是一個開關:按下時兩端接通,放開時斷開。但這裡有個初學者必踩的坑:**「懸空」的腳位讀到的值是不確定的。**

如果你只把按鈕接在「腳位 ↔ GND」之間:

- 按下:腳位接到 GND → 讀到 **低電位 (0)**,很明確。
- 放開:腳位**什麼都沒接**,像天線一樣飄 → 讀到的值忽 0 忽 1,**不可靠!**

解決辦法是加一個 **上拉電阻 (pull-up resistor)**,讓「放開」時腳位有個明確的預設電位:

```
        VDD (3.3V)
          │
        [ 上拉電阻 10kΩ ]      ← 放開時把腳位「拉」到高電位
          │
   P1.5 ──┴────────[ 按鈕 ]──── GND
```

- **放開**:沒電流過電阻,P1.5 被拉到 VDD → 讀到 **高電位 (1)**。
- **按下**:P1.5 直接接到 GND(電阻只是限流)→ 讀到 **低電位 (0)**。

> 這種「平常是 1、按下變 0」的接法非常常見,叫做 **低電位有效 (active-low)**。記住:**按下 = 讀到 0**。

### 好消息:N76E003 可以不用外接電阻!

N76E003 的腳位在**準雙向模式**下,內部本身就帶有「弱上拉」。所以這一課我們把按鈕腳設成**準雙向模式(預設值)**,就能省掉外接的上拉電阻,只要:

```
   P1.5 ────────[ 按鈕 ]──── GND
```

放開時內部弱上拉把它拉到 1,按下時被拉到 0。簡單!

> ⚠️ 注意:要讀取一支準雙向腳的外部輸入前,軟體要先對它**寫入 1**(讓它處於「放手讓外界決定」的狀態)。這是 8051 準雙向腳的特性,範例程式會示範。

## 3.3 程式邏輯

核心就一句話的判斷:

```c
if (SW == 0)        // 按鈕被按下(低電位有效)
    LED = LED_ON;
else
    LED = LED_OFF;
```

其中 `SW` 是我們幫 P1.5 取的名字,`LED` 是 P1.4。整個主迴圈不斷地「看按鈕、決定 LED」:

```c
while (1)
{
    if (SW == 0)
        LED = LED_ON;
    else
        LED = LED_OFF;
}
```

這種「一直反覆檢查某個輸入」的做法叫 **輪詢 (polling)**。簡單直覺,是初學的首選。

---

## 3.4 設定:一支輸出、一支輸入

初始化時要分別設定兩支腳:

```c
// P1.4 → 推挽輸出(驅動 LED,同第 1 課)
P1M1 &= ~(1 << 4);
P1M2 |=  (1 << 4);

// P1.5 → 準雙向(讀按鈕,用內部弱上拉)
P1M1 &= ~(1 << 5);
P1M2 &= ~(1 << 5);

SW = 1;   // 讀取前先寫 1,讓準雙向腳能被外界拉低
```

> 開機後腳位預設就是準雙向,所以 P1.5 那兩行其實可省略;這裡寫出來是為了讓你「看清楚每支腳被設成什麼」,養成好習慣。

---

## 3.5 關於「彈跳 (bounce)」

機械式按鈕在按下的那一瞬間,金屬接點會「彈跳」好幾下,產生一連串快速的 0101 雜訊,時間約幾毫秒。

- 對這一課「按著就亮」的用法,彈跳**沒有影響**(反正最後都穩定在 0)。
- 但如果你想做「按一下計數 +1」,彈跳會讓一次按壓被誤算成好幾次。

**最簡單的去彈跳 (debounce) 方法:偵測到狀態改變後,延時約 20ms 再確認一次。** 這個技巧留到練習,先把基本的讀取學會。

## 3.6 C 與組語對照

| 做的事 | C 語言 | 組合語言 |
|--------|--------|----------|
| 讀按鈕並判斷 | `if (SW == 0) ...` | `jb P15, led_off`(P1.5=1 就跳去關燈)|
| 開燈 | `LED = 1;` | `setb P14` |
| 關燈 | `LED = 0;` | `clr P14` |

組語用 **`jb` / `jnb`**(jump if bit / jump if not bit)這類「位元判斷跳躍」指令來做 `if`:

```asm
loop:
    jb   P15, led_off    ; 若 P1.5 = 1(放開)→ 跳去關燈
    setb P14             ; 否則(按下)→ 開燈
    sjmp loop
led_off:
    clr  P14
    sjmp loop
```

看懂了嗎?C 的 `if/else` 在組語裡,就是「**用位元判斷決定要不要跳過某段程式**」。這是理解所有高階語言流程控制的根本。
